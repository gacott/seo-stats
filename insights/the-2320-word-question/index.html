The 2,320-word question

By Ivo Petrov · 2026-01-10
Insights
All insightsStatisticsMethodology

The average first-page result in our reference runs to 2,320 words. Every few months this figure is recycled as advice: write longer posts. That is a category error.

The measurement describes the pages that rank. It does not show that length causes ranking. Long pages tend to be long because the query is broad and the topic has depth; a narrow query is often served best by a short, precise answer.

Length is a symptom

When we look at pages that answer the query within the first hundred words — 63.1% of top results do — the pattern that matters is intent match, not word count. A 900-word page that resolves the question can outrank a 3,000-word page that circles it.

How to use the number

Use it as a benchmark for competitive breadth, not a target. If your page is far shorter than the ranking set and leaves parts of the query unanswered, length is worth revisiting. If it is shorter and complete, leave it alone.
