Glossary

Working definitions for the terms used throughout the reference.

AI overview

A generated summary shown above or within search results.

Anchor text

The visible, clickable text of a link.

Backlink

A hyperlink from another site pointing to a page.

CAC

Customer acquisition cost — total spend divided by new customers acquired.

Canonical

A signal telling search engines which URL is the preferred version of a page.

Core Web Vitals

A set of field-performance metrics (LCP, INP, CLS) used as page-experience signals.

Crawl budget

The amount of crawling a search engine is willing to spend on a site in a period.

CTR

Click-through rate: clicks divided by impressions for a result or ad.

Domain Authority

A third-party authority score; not used by Google but widely used as a comparative proxy.

E-E-A-T

Experience, Expertise, Authoritativeness and Trust — a quality heuristic, not a direct ranking factor.

Hreflang

Markup that tells search engines which language or region a page targets.

Index bloat

Low-value or duplicate URLs that consume indexing capacity without earning traffic.

Local intent

A query where the searcher is expected to want results near a location.

Map pack

The block of local business results shown for local-intent queries.

Organic traffic

Visits that arrive from unpaid search results rather than ads or direct navigation.

Position

The rank of a result on the SERP for a given query.

Referring domain

A distinct website that links to a page; counted once regardless of how many links it places.

SERP

Search engine results page — the page a search engine returns for a query.

Structured data

Machine-readable markup (usually JSON-LD) that describes page content.

Zero-click search

A search that ends on the results page without a click to any result.
